## 走訪
### 前序/中序/後序
以**根節點**為參考點而定的走訪順序，決定走訪的順序：
- 前序：根結點 -> 左子樹 -> 右子樹
- 中序：左子樹 -> 根結點 -> 右子樹
- 後序：左子樹 -> 右子樹 -> 根結點
### 以走訪順序回推結構
通常一個中序搭配一個前序或後序
1. 前/後序：判斷根節點
2. 中序：判斷左右子樹
3. 遞迴套用 1. 2. 到左右子樹

可參考：https://ithelp.ithome.com.tw/articles/10205571

#TeacherSelection 
AVL Tree 是一種二元搜尋樹，在 insert 與 delete 的時候，檢查平衡狀態，必要時做旋轉調整，以避免變成歪斜樹，確保搜尋效率。

## 平衡因子（balance factor）
- 定義："左子樹高度" 減去 "右子樹高度" 的絕對值
- 限制：AVL Tree 中，所有節點的平衡因子都要保持 <= 1，否則即為失衡
- 用途：在失衡的時候判斷要執行哪一種旋轉

## 旋轉
### 旋轉類型

| 類型  | 判斷方式                      | 旋轉方式                        | 衝突節點處理 |
| --- | ------------------------- | --------------------------- | ------ |
| LL  | 某節點平衡因子為 -2，其左子節點平衡因子為 -1 | 右旋 (-2 的結點順時針轉，變成 -1 的右子結點) | 右子變左子  |
| RR  | 某節點平衡因子為 -2，其右子節點平衡因子為 -1 | 左旋 (-2 的結點順時針轉，變成 -1 的左子結點) | 左子變右子  |
| LR  | 某節點平衡因子為 2，其右子節點平衡因子為 -1  | 左子樹先做左旋，然後整體做右旋             |        |
| RL  | 某節點平衡因子為 2，其右子節點平衡因子為 1   | 右子樹先做右旋，然後整體做左旋             |        |
### 多點失衡
在 insert 或 delete 節點的時候，可以根據平衡因子判斷要執行哪一類的旋轉。如果有多個祖先（?）節點失衡，則優先處理**最靠近**上一次操作的失衡節點

### 效能影響
- 單次旋轉 O(1)
- 累積多 (n) 次旋轉 (worst case) O(n)
- 由於旋轉前、後中序走訪等價，所以不會破壞資料的排序性，可以確保搜尋效率

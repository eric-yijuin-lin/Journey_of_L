#TeacherSelection
## 常見系統
| **簡寫**   | **全名**                         | **簡要說明**                                                 |
| -------- | ------------------------------ | -------------------------------------------------------- |
| **GFS**  | Google File System             | Google 開發的分散式檔案系統，主要用於處理大規模資料；HDFS 的設計概念受到 GFS 論文影響。     |
| **NTFS** | New Technology File System     | Microsoft Windows 常用的本機磁碟檔案系統，支援權限、加密、壓縮與日誌功能，並非分散式檔案系統。 |
| **NFS**  | Network File System            | 一種網路檔案系統，讓使用者可透過網路存取遠端主機的檔案，常見於 Unix/Linux 環境。           |
| **HDFS** | Hadoop Distributed File System | Hadoop 的主要分散式檔案系統，會將大型檔案切割並分散儲存在多台伺服器上，具備容錯與高吞吐量特性。      |

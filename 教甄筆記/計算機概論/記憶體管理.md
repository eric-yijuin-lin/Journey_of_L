#TeacherSelection 
## Paging
Paging (分頁) 記憶體管理，把記憶體空間切割為若干大小的 frame，載入程序需要的資料到 frame，以運行程序。

### Page Fault
- 如果程序需要執行時，所有 frame 都被佔滿，必須把某個 frame 踢出，載入程序需要的資料。這種情況就叫 **Page Fault** (被踢出的 frame 就叫 Victim Page) 
- 初始狀態如果記憶體為空，此時程序找不到所需的站存
### Reference String
代表程序需要的記憶體參考位置的序列，需要用此來判斷所需的資料有沒有在 frame**s** 裡，計算 Page Fault 的次數

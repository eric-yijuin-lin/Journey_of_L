#TeacherSelection 

Expression Tree

### 規則
* 把數值與運算子視為樹的節點
* 以前/中/後序建立 tree
* 還原運算式然後計算結果
	* 如果沒有指定，預設是中序走訪

### 例題
Q: 若有一棵運算樹(expression tree),葉節點 A=3、B=4、C=8、D=5,其前序走訪所得
運算式為:

```
* + A B − C D
```
請問此運算式的計算結果為何?

A: 因為是前序，所以畫出來的 tree 是
```
        *
       / \
      +   −
     / \ / \
    A  B C  D
```

還原為運算式得到：
```
  (A+B) * (C-D) 
= 7 * 3
= 21
```

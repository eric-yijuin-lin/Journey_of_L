1. [VS code] 信任資料夾
	- 新版不知道為什麼，有時候不會自動問要不要信任資料夾，Python Extension 不會自己啟動。需要切 terminal 或到 Extension 管理的地方點選 Enable 然後信任
2. [UV] 建立新專案
	- `uv init --python 3.12 project_name`
	  `cd project_name`
3. [UV] 
	- 安裝 Jupyter 核心
		- `uv add --dev ipykernel`
	- 選擇 Interpreter
		- 這次右上角的 Jupyter Kernel 選擇按鈕會跳掉，需要自己
		  `Ctrl + Shift + p` -> `Select Interpreter`
	- 安裝 Jupytext
		- `uv add --dev jupytext`
		- Jupytext 常用指令
			- 轉成 py: `jupytext --to py:percent target.ipynb`
			- 轉回 ipynb: `jupytext --to ipynb source.py`
		- 建議上 git 的檔案
			- `target.py`
			- `pyproject.toml`
4. [CUDA]
	- 安裝 CUDA、CUDNN
	- 檢查狀態: `nvidia-smi`
	- 2026/08/19 專案版本資訊：
		- Python: 3.12
		- cuda: 12.6  
		- torch: cu126
5. [Ultralytics]
	- ultralytics 預設安裝 cpu 版本，必須明確指定 cuda 版本
		- `uv add torch torchvision --index pytorch=https://download.pytorch.org/whl/cu126`
6. [UV]
	- 在另一台電腦同步 uv 環境: `uv sync`

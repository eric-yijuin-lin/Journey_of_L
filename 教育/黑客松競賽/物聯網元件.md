## 分貝計
- 元件型號：INMP441
- (By AI) ESP32 比 Arduino 適合，因為 ESP32 有 I2C 硬體
- 接線圖（GPIO 可以調整）

| ESP32   | INMP441 左 | 備註                      |
| ------- | --------- | ----------------------- |
| GND     | GND       |                         |
| 3V3     | VDD       |                         |
| GPIO 33 | SD        |                         |
| GND/3V3 | L/R       | 接地代表收左聲道<br>接3V3 代表收右聲道 |
| GPIO 25 | WS        |                         |
| GPIO 26 | SCK       |                         |


- 實作步驟：

| 部分          | 建議                    |
| ----------- | --------------------- |
| INMP441 I²S | ESP32 官方 I²S driver   |
| DMA buffer  | 官方 I²S driver         |
| DC blocker  | 現成 IIR / 自己幾行         |
| INMP441 EQ  | 採用現成 coefficients     |
| A-weighting | 採用現成 IIR coefficients |
| RMS         | 自己寫，很簡單               |
| LAeq        | 自己寫，很簡單               |
| dB SPL 換算   | 自己寫公式                 |
| 校正 offset   | 自己設定一個參數              |
| FFT         | 需要時再用 ESP-DSP         |

- 其他候選
	- ADIO-FC04
	- LM386
